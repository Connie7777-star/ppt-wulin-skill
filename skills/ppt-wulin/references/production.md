# 制作路线与页面提示

## 按后续使用选择

| 需求 | 适合路线 | 注意事项 |
| --- | --- | --- |
| 持续修改文字、数字、图表 | 原生可编辑 PPTX | 检查对象可编辑性、字体替代和图表数据 |
| 静态放映、强调版式稳定 | 整页图片装入 PPTX | 文字不可直接编辑，清晰度依赖图像，文件不一定更小 |
| 高视觉质量同时保留关键内容可改 | 图片背景加原生文本／图表 | 背景不应烘焙同一段文字，避免覆盖时重影 |
| 浏览器演示或交互 | HTML 演示 | 仅在用户接受该格式时采用；说明离线与导出能力 |

不要把“整页截图插入 PPT”称为原生可编辑演示文稿。需要兼容稳定展示时，可以保留可编辑源文件并另给静态版本，前提是任务有此需要。

## AI 素材与页面生成

先确定整套的视觉约定：画幅、主题色、强调色、插画或摄影风格、留白方式、主体位置。先做代表页面验证风格，再扩展到同类页面，避免反复全量生成。

可用提示结构（按实际任务填充，删除无关项）：

```text
页面用途：[教学／汇报／比赛／讲座]；听众：[人群]。
这一页的唯一重点：[一句话观点]。
必须准确保留的信息：[文字、数字、单位；不添加材料以外的数据]。
视觉关系：[比较／过程／时间／一个核心数字／单图配一句话]。
风格：[与已确定视觉体系一致的具体描述]。
配色与画幅：[沿用整套设定]。
布局：[主体位置、文本区域、留白]。
生成范围：[只有配图／无字背景／完整静态页面]。
编辑要求：[哪些内容稍后以原生文本或图表添加]。
```

生成素材时优先避免把关键文字和精确数据写进图片；需要整页生成时逐字检查中文字形、数字、单位与图表标注。数据图表应由准确的数据构建，不能靠生成图像猜测柱高或曲线。

遇到错字时，优先移除错误文字所在的背景内容，再添加可编辑文本；不能简单叠字掩盖仍可见的旧文字。字体、插画细节和背景不一致时，针对问题页修正，不随意改变已通过的整套风格。

## 工具与素材

原文提及的 Kimi、WPS、豆包、Canva、PPT Master、Frontend Slides 等属于作者当时的工具示例，不构成固定依赖或当前能力保证。选择工具时依据当前可用能力与用户指定格式；需要推荐某个服务时，另行核实其现状。

使用用户提供或有适当使用许可的模板、图片和字体；记录需要随成品保留的来源或署名。无需将使用过的外部模板、字体和原始材料一起公开发布。
