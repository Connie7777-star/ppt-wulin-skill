# PPT 武林秘籍 · ppt-wulin

先找到 **Point**，再做 **PowerPoint**。

将《【260923】PPT武林秘籍》中的“PPT 修仙六境”整理为可复用的 Agent Skill，适用于教学课件、汇报、比赛和讲座。它帮助 AI 梳理观点、优化页面、改造模板并选择合适的制作方式。

## 六境

| 境界 | 核心能力 |
| --- | --- |
| 练气 | 先做出可用初稿 |
| 筑基 | 对齐、重复、对比、亲密与统一配色 |
| 结丹 | 提炼整场与每页的 Point |
| 元婴 | 让模板与素材适合自己的内容 |
| 化神 | 用 AI 辅助素材、版式和演示制作 |
| 大乘 | 精简信息，让页面服务表达 |

六境是能力地图，不是必须逐关完成的流程。

## 安装与使用

仓库中的 Skill 目录为 [`skills/ppt-wulin`](skills/ppt-wulin)。将完整目录复制到所用 Agent 的技能目录。Codex 默认可放在 `~/.codex/skills/ppt-wulin`；设置了 `CODEX_HOME` 时使用该目录下的 `skills/ppt-wulin`。

示例请求：

```text
请使用 $ppt-wulin，把这份讲稿做成 15 分钟教师培训 PPT，文字和图表需要可编辑。
```

```text
请使用 $ppt-wulin，检查这份汇报的核心观点、页面层级和配色，保留现有模板。
```

```text
请使用 $ppt-wulin，我只有 30 分钟准备一场无网络比赛，先帮我提炼每页的重点。
```

## 包含什么

- `SKILL.md`：触发范围、观点梳理、六境工作流。
- `references/production.md`：原生可编辑、整页图片、混合与网页演示的选择方法，以及页面提示结构。
- `references/review.md`：内容、视觉与文件交付检查。
- `agents/openai.yaml`：Codex 界面名称与默认提示。

此 Skill 是方法与工作流程，不自带 PPTX 渲染器或商业服务账号。生成实际文件需要运行环境具备相应工具；不将图片型幻灯片宣称为原生可编辑 PPT。

## 来源与整理原则

根据用户提供的《【260923】PPT武林秘籍》提炼。保留六境、四项设计原则、Point 优先、模板改造、AI 辅助和大道至简等方法；将个人经验转为按场景选择的建议。交付校验和生成图片文字检查属于将方法落地为 Skill 时补充的执行规则。

仓库不包含原始 Word 文件、个人路径、文档元数据或第三方模板。原文中的产品名称仅视为示例，不保证其当前功能。
